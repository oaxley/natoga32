# NATOGA32 - Not an Atari nor an Amiga 32-bit

## Presentation

This is the technical documentation for the `natoga32` virtual console.  
The sources and documentations are under the MIT License, so you are free to 
use it, modify it or even be inspired by it.  
I do not, however, provide any support. This is a toy project I do on my spare
time, just for fun and keep my 
C++ & Go up to date.  
There is no agenda when it will be finished (if it is one day) or when a 
particular piece of code will be implemented.


## But why?

A couple years ago, I developed some 90's demoscene effects, mainly to try
TypeScript. It was fun and reminded me the time where I was doing LAN parties
and coding challenges over a weekend. Computers were heavy (especially monitors)
very slow, but we managed to extract every MHz to create "WoW" effects. It was
way before everybody moved to 3D and GPUs.  
This project is my attempt to recreate these 90's computers, with limited hardware
and resources, but a lot of fun to program.
